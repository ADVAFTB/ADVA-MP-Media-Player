# ADVA Media Player

**[English](README.md) · Русский**

ADVA Media Player — настольный музыкальный плеер для Windows на базе Electron. Он объединяет воспроизведение локальных аудиофайлов, интеграции с онлайн-каталогами музыки, встроенный эквалайзер, синхронизированные тексты песен/субтитры и многоязычный интерфейс.

> **Статус проекта:** это независимый личный проект. Обновления могут выходить нерегулярно, а онлайн-интеграции могут переставать работать после изменений сторонних сервисов. Некоторые визуальные недочёты и проблемы с обложками могут оставаться.

## Возможности

- **Локальное воспроизведение:** MP3, WAV, OGG, FLAC, M4A и AAC.
- **Онлайн-каталог музыки:** интеграции с YouTube Music, Zvuk и поиск через Muzofond.
- **Тексты песен и субтитры:** сейчас поддерживаются в интеграциях YouTube Music и Zvuk; доступность зависит от того, предоставляет ли сервис текст для конкретного трека.
- **Эквалайзер и управление воспроизведением:** громкость, настройки баса, аудиорежимы, случайный порядок и повтор.
- **Библиотека и локальный профиль:** настройки приложения и данные библиотеки хранятся на компьютере.
- **Темы и локализация:** тёмная, чёрная и светлая темы. По умолчанию интерфейс на английском; также есть русский перевод. В текущем исходном коде присутствуют японские строки интерфейса, однако их поведение может различаться между сборками.

## Начало работы

### Для слушателей

1. Откройте раздел **Releases** этого репозитория.
2. Скачайте подходящую сборку для Windows. Версия **Setup** предназначена для установки, а **Portable** — для портативного запуска.
3. Запустите ADVA Media Player и завершите первоначальную настройку локального профиля и языка.
4. Откройте **Каталог музыки**, выберите сервис и найдите трек или исполнителя. Для воспроизведения файлов с компьютера используйте команду открытия локального аудиофайла.

Основная сборка на Electron 28 предназначена для **Windows 10 и Windows 11** и не поддерживает Windows 7. Отдельная Legacy-сборка на старой ветке Electron может публиковаться отдельно. Используйте её только в том случае, если она явно доступна в Releases и была проверена на вашей системе.

### Подключение Звука

1. Откройте **Каталог музыки → Звук → Подключить аккаунт**.
2. В окне подключения откройте официальный сайт Звука и выполните вход там.
3. Не закрывайте окно подключения; вернитесь в ADVA и нажмите **«Я вошёл — подключить аккаунт»**.
4. После успешного подключения выполните поиск музыки в разделе Звук.

Приложение рассчитано на то, чтобы читать токен сервиса только после явного подтверждения подключения пользователем. Пароль от аккаунта приложение намеренно не сохраняет. Если доступно системное защищённое хранилище Electron `safeStorage`, токен шифруется перед записью в локальные данные приложения. При этом токен остаётся конфиденциальной информацией: не передавайте его другим и не публикуйте папку данных приложения. Интеграция не обходит ограничения аккаунта, подписки, доступности треков, региона или правообладателей.

**YouTube Music:** текущая интеграция не требует входа в Google-аккаунт. Доступность треков и воспроизведение всё равно могут зависеть от страны, сети и изменений стороннего сервиса.

## Сборка из исходного кода

### Требования

- Для создания и проверки Windows-сборок рекомендуется Windows.
- Node.js и npm.
- Исходные файлы проекта, включая `main.js`, `index.html`, `locales.js` и `sub.js`.
- Файлы `ytmusic_bridge.exe` и `zvuk_bridge.exe` рядом с исходниками для обычного процесса сборки. Если требуется пересобрать мосты, установите Python 3.10 или новее и используйте включённые BAT-скрипты.

### Запуск в режиме разработки

1. Скачайте или клонируйте репозиторий и откройте терминал в папке проекта.
2. Установите зависимости Node.js:

   ```bat
   npm install
   ```

3. Убедитесь, что приложению доступны оба EXE-моста. Для пересборки используйте подходящий скрипт `build_ytmusic_bridge.bat` или `build_zvuk_bridge.bat`. Скрипты загружают зависимости Python, поэтому потребуется интернет.
4. Запустите приложение:

   ```bat
   npm start
   ```

### Сборка для Windows

Эти команды доступны, если в `package.json` определены соответствующие скрипты и EXE-мосты готовы:

```bat
npm run dist:nsis
npm run dist:portable
npm run dist:all
```

- `dist:nsis` — создать установщик Windows.
- `dist:portable` — собрать отдельную портативную версию.
- `dist:all` — собрать все цели, настроенные в `package.json`.

Результат сборки сохраняется в настроенную папку `dist`. Перед публикацией обязательно проверьте установщик и Portable-сборку на чистой Windows. При упаковке через Enigma Virtual Box сначала проверьте обычную сборку `win-unpacked`: виртуализация не гарантирует совместимость Electron и дочерних EXE-мостов.

## Что использует проект

- **Electron** — среда настольного приложения (Chromium + Node.js).
- **HTML, CSS и JavaScript** — интерфейс приложения.
- **`locales.js`** — строки интерфейса и переводы.
- **`sub.js`** — логика текстов песен и субтитров.
- **Python-мосты в формате EXE** — отдельные процессы для интеграций с музыкальными сервисами.
- **`ytmusicapi` и `yt-dlp`** — используются мостом YouTube Music.
- **`zvuk-music`** — используется мостом Звука.
- **Electron `safeStorage`** — шифрует сохранённый токен Звука, если доступно системное защищённое хранилище.

## Известные ограничения

- Сторонние сервисы могут без предупреждения менять API, процесс авторизации, потоковое воспроизведение и адреса обложек.
- Доступность треков, воспроизведение полной версии и качество зависят от сервиса, аккаунта, региона, подписки и настроек правообладателей.
- Синхронизированные тексты/субтитры доступны не для всех треков и сейчас интегрированы только с YouTube Music и Звуком.
- Некоторые иконки или обложки могут не загружаться. Исправления и новые версии не гарантированы по фиксированному графику.
- Если публикуется Legacy-версия для Windows 7, она использует старую и неподдерживаемую версию Electron и не получает обновлений безопасности современных выпусков Electron.

## Конфиденциальность и безопасность

- Локальный профиль, настройки и библиотека хранятся в папке данных приложения на компьютере пользователя.
- Токены авторизации Звука являются конфиденциальными данными. Защищайте учётную запись Windows и не публикуйте логи или локальные файлы, которые могут содержать сведения о сессии.
- Используйте онлайн-интеграции в соответствии с условиями соответствующих сервисов и местным законодательством.
- ADVA Media Player — независимый проект, не связанный с Google, YouTube, Звуком, Muzofond или СберБанком.
